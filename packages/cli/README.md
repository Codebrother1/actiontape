# actiontape

The ActionTape command line: deterministic record and historical-analysis
tooling for AI agent tool calls over MCP.

```sh
npm install -g actiontape
actiontape --help
```

**Experimental v0.1.** Requires Node.js 22 or later. See the
[ActionTape repository](https://github.com/Codebrother1/actiontape) for project
documentation.
