# @actiontape/core

Protocol-independent `ActionEnvelope` domain model, event vocabulary, and
JSON-safety primitives for ActionTape — the deterministic record and
historical-analysis layer for AI agent tool calls.

**Experimental v0.1.** Requires Node.js 22 or later. See the
[ActionTape repository](https://github.com/Codebrother1/actiontape) for project
documentation.
