# @actiontape/authzen

AuthZEN/COAZ-MCP support for ActionTape: the COAZ-MCP Draft 1 default
`tools/call` mapping, declared-mapping CEL renderer, AuthZEN Access
Evaluation(s) clients, and sequential simulation/audit engines.

**Experimental v0.1.** Requires Node.js 22 or later. See the
[ActionTape repository](https://github.com/Codebrother1/actiontape) for project
documentation.
